# Moments for Android

Cliente Android de Moments (Kotlin + Jetpack Compose). Package Play: `com.momentsapp`.

## Abrir en Android Studio

1. Abre esta carpeta `MomentsAndroid`.
2. JDK 17+.
3. Sync Gradle.
4. Para release firmado: `keystore.properties` local (ver `keystore.properties.example`; no se sube al repo).
